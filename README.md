# たまり場

創作キャラクターが勝手に遊びに来るのを集めるゲーム。スマホのブラウザで動きます。

## ファイル

```
atsume/
├── index.html        これ1つがゲーム本体
├── characters.txt    誰が来るか
├── items.txt         何を置けるか
├── skins/            マイクラスキンのPNG
└── items/            グッズの画像（使わなくてもいい）
```

## 遊びかた

グッズを置いてアプリを閉じ、しばらくしてから開くと誰かが来ています。押すと喋って、思い出がもらえます。帰った人はおみやげを置いていきます。思い出が貯まると新しいグッズが買えて、置くものが変わると来る人も変わります。

来るかどうかの判定は20分ごとです。1時間で1〜2人、一晩あければおみやげが7個くらい溜まります。

## スマホに入れる（自分用）

そのままだと、スマホでファイルを開いても `characters.txt` が読み込めません。ブラウザの安全上の決まりで、ローカルのファイル同士を読み合えないためです。**ウェブに置く必要があります。**

## ウェブに置く（友達に配る）

GitHub Pages が無料で、この用途にちょうどいいです。

1. [github.com](https://github.com) でアカウントを作る
2. 新しいリポジトリを作る（名前は `tamariba` など。**Public** にする）
3. `index.html` `characters.txt` `items.txt` と `skins` フォルダをまとめてアップロードする
4. リポジトリの Settings → Pages → Source を `main` ブランチにして保存
5. 数分待つと `https://ユーザー名.github.io/tamariba/` で開けるようになる

このURLを送れば、友達はリンクを開くだけで遊べます。iPhoneならSafariの共有ボタン →「ホーム画面に追加」、Androidならメニュー →「ホーム画面に追加」で、アプリのように起動できます。

**セーブデータはそれぞれの端末に保存されます。** 誰が何人集めたかは共有されません。各自の記録帳になります。

## キャラを増やす

`skins` にPNGを置いて、`characters.txt` に追記するだけです。

```
= ユリウス
# スキン
ユリウス.png
# 好きなもの
本の山
# セリフ
ここは、居心地がいいですね
# セリフ_夜
まだ起きていらしたのですか
# おみやげ
押し花のしおり
# レア
2
```

`レア` は数字が大きいほど来にくくなります。1が普通、5でかなりの珍客です。全員1でも成立します。

`腕` に `細` と書くとスリム体型（腕3px）になります。省略するとクラシック（4px）です。

**スキンPNGが無くても動きます。** 影絵のような仮の姿で出てくるので、先に名前とセリフだけ書いておいて、絵は後から足せます。

## グッズを増やす

`items.txt` に追記します。`値段` を0にすると最初から持っている状態になります。

```
= 剣の手入れ道具
# 値段
80
# 絵文字
🗡
# 説明
使い込まれている
```

**`好きなもの` に書いた名前と、グッズの名前は完全に一致させてください。** ズレていると、そのグッズを置いてもその人は来やすくなりません。

絵文字のかわりに画像を使いたい時は `# 画像` に `items/樽.png` のように書きます。24×24pxくらいのPNGが目安です。

## 調整できるところ

`index.html` の中ほど、`const SPOTS` のあたりに数字がまとまっています。

| 名前 | 意味 |
|---|---|
| `ROUND_MS` | 来るかどうかを判定する間隔（初期値は20分） |
| `ARRIVE_P` | 1回の判定で来る確率（初期値0.35） |
| `GREET_REWARD` | 話しかけた時にもらえる思い出 |
| `GIFT_REWARD` | おみやげ1つぶんの思い出 |

## いま入っていないもの

写真を撮る機能、模様替え、キャラ同士の絡み。どれも後から足せます。まずは来て、喋って、集まるところまでです。
